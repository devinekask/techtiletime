The most easy way to get a vector file plotted is to use the web interface 'saxi'. You could install this on your own machine and connect the plotter via USB to your computer. But we've provided a Raspberry Pi which is connected to the plotter, has Saxi installed and is available on the eduroan-2.4 WiFi.

## Steps

1. Switch the 'Motor Power' on
2. Connect to the `eduroam-2.4` wifi network
3. Open a browser and go to <http://harryplotter.technet.howest.be:9080/>
4. Drag your SVG file on te canvas
5. Set hardware to 'AxiDraw V3 Brushless'
6. Adjust settings if needed
7. Align the paper, fix it in place with some magnets (check if they aren't in the path of the plotter)
8. Click the 'pen up' button, the penclip should be raised up then.
9. Mount the pen, make sure its point is hovering a couple of millimeters above the paper
10. Plot!
11. Switch the 'Motor Power' off when done
